    Похожие кадры одного насоса — одна группа. Если неизвестно, оставь пустым: уточним перед обучением.

    Как размечать

    1. Выбери класс справа. Обведи повреждённый участок, а не весь агрегат.

    2. Несколько отдельных повреждений — несколько рамок. Удали ошибочную рамку кнопкой ×.

    3. После проверки всех областей нажми «Готово». Для чистого снимка — «Видимых дефектов нет».

    4. Неразборчивое фото, схема или сомнительный диагноз — «Не уверен». Такие снимки не попадут в обучающие метки.

    5. Рамки сохраняются автоматически. «Готово» отдельно подтверждает правильность разметки.

    1–9, 0 — класс; ← → — фото; Enter — готово; Ctrl+Z — убрать рамку; Esc — отменить выделение.

    Размечаем только видимые признаки. Название файла не является подтверждённым диагнозом. Обучение начнётся после проверки разметки и разделения независимых групп.
